# Керим Отаров — новая визуальная и информационная архитектура

## Почему изменена композиция

Предыдущая версия имела две совмещённые главные страницы: длинный исходный лендинг и ещё шесть анимированных карточек-переходов. Повторение навигации делало структуру непонятной, а текстовые стрелки выглядели не как UI-система.

Новая схема: короткий кинематографический портрет → один блок с тремя путями → минимальный футер. На внутренних страницах — собственное содержимое без пересказа главной. Шесть постоянных разделов открываются через полноэкранное меню; в шапке показаны самые частые три.

## Визуальная режиссура

- Подлинный архивный портрет, тёплый чёрно-белый тон и мягкая глубина слоёв.
- Тёмный графитово-синий, бумажный слоновый и приглушённая бронза; Cormorant Garamond + Manrope.
- Кинетическое раскрытие двух строк имени; 2.5D-параллакс фотографии и светового слоя от указателя.
- Меню открывается полноэкранной вертикальной шторкой, пункты проявляются последовательно, фоновой фотографией задаётся глубина сцены.
- Переход из обложки в читательскую страницу через общую пару элементов в View Transitions API.
- Обложки наклоняются в перспективе от положения указателя. Круглые SVG-кнопки с физической магнитной реакцией.
- Набор иконок единый: stroke 1.45–1.5, одинаковая оптическая геометрия, никаких декоративных стрелок Unicode.
- При ограничении анимаций в ОС движения выключаются; на сенсорных устройствах эффект наведения не используется.

Это оригинальная адаптация принципов Lusion (движение, глубина, цельный переход), а не воспроизведение их WebGL-кода или 3D-сцен.

## Навигация и содержание

Сохраняются глубокие ссылки `#/... `, назад/вперёд, глобальный поиск, личные заметки, переключение языков, фильтры библиотеки и выбранные слова. Полные тексты, реальное аудио и мемориальные координаты добавляются только с проверенными источниками.

## Проверки

Playwright: desktop Chrome 1440×900 и профиль Pixel 7; прямые URL, навигация, обратный переход, поиск, меню, SVG, уменьшение движения, интерактивные обложки, читальный зал, сохранение, горизонтальная прокрутка. GitHub Actions сохраняет скриншоты.
