# Керим Отаров — литературное наследие

Литературный портал поэта Керима Сарамурзаевича Отарова. Структура наследия организована как самостоятельные страницы: жизнь, творчество, медиа, память, проекты и афиша.

## Публикация

Сайт размещается на GitHub Pages из корня ветки main:
https://karachay-malkar.github.io/kerimotarov.ru/

Сборка не нужна. Для локального запуска:

```bash
python3 -m http.server 8000
```

## Навигация

Используются маршруты после `#/`, чтобы GitHub Pages открывал страницы после обновления вкладки и по прямой ссылке:

- `#/life` — биография, хронология, география и семья
- `#/works` — библиотека и фильтры; `#/works/roads` — читальный зал
- `#/media` — аудио, фото и видео
- `#/memory` — места памяти, воспоминания и публикации
- `#/projects` — словарь, параллельное чтение, образование
- `#/events` — афиша; `#/events/example` — демонстрационная страница события

Поддерживаются браузерные «Назад» и «Вперёд», прямые ссылки, поиск по порталу (Ctrl/Cmd+K), полноэкранное меню, настройки читателя и локальные заметки.

## Устройство

- `index.html` — первоначальная главная страница, архивный портрет и секции
- `style.css` и `app.js` — исходный макет с существующими функциями
- `portal.css` и `portal.js` — новые самостоятельные страницы, анимации и маршрутизатор
- `assets/` — реальный архивный портрет, шрифты и лицензии
- `tests/portal.spec.cjs` — браузерные тесты

## Проверки

```bash
npm install
npx playwright install chromium
npm run check
npm test
```

GitHub Actions автоматически выполняет проверки в Chromium с размерами экрана компьютера и телефона. Статус и ограничения — в VERIFICATION.md.

## Ограничения содержания

Это работающая структура портала, не полный оцифрованный архив: полные тексты, аудио и видео не предоставлены и не имитируются. Пробный перевод фрагмента — предварительный подстрочник. Публичные анонсы не вымышлены, а демонстрационная страница мероприятия явно помечена. Для публикации архивных документов требуются подтверждение происхождения и прав. Источники указаны в SOURCES.md.
