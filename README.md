# Керим Отаров — литературный портал

Цифровое литературное наследие Керима Отарова: биография, поэзия и переводы, фото- и аудиоархив, память, образовательные материалы и афиша.

**Публичный сайт:** https://karachay-malkar.github.io/kerimotarov.ru/

## Новая структура

Короткая главная: портрет поэта, один главный призыв к чтению и три входа — жизнь, книги и архив. Все шесть полных разделов собраны в полноэкранном меню. Второй лендинг и дублирующиеся страницы удалены.

- `#/life` — биография и интерактивная хронология, `#/life/chronology` — вся последовательность дат.
- `#/works` — библиотека, поиск, фильтры, переход с обложки в произведение.
- `#/works/roads` — читальный зал с оригиналом и предварительным русским подстрочником, локальными заметками и сохранением.
- `#/media` — авторский голос, чтения, архивные фотографии, видео.
- `#/memory` — памятные места, воспоминания и публикации.
- `#/projects` — живой словарь и параллельное чтение.
- `#/events` — афиша; неподтверждённые встречи не представляются реальными.
- `#/sources` — ссылки на подтверждаемые материалы.

GitHub Pages поддерживает прямые ссылки и назад/вперёд благодаря маршрутам после `#/`.

## Архитектура

Чистый статический сайт без JS-фреймворка и обязательной сборки:

- `index.html` — общий каркас, семантическая навигация, поиск, меню;
- `site.css` — типографика, сцены, сетки, иконки, анимации, мобильные состояния;
- `site.js` — данные страниц, маршрутизация, поиск, читатель, события и интерактивные эффекты;
- `assets/` — локальные шрифты и подтверждённая архивная фотография;
- `tests/portal.spec.cjs` — браузерные проверки для телефона и компьютера.

Устаревшие файлы предыдущих лендингов удалены из текущей ветки. История изменений сохранена в Git.

## Запуск и проверка

```sh
python3 -m http.server 8000
npm install
npx playwright install chromium
npm run check
npm test
```

GitHub Actions выполняет браузерные тесты Chromium и прикладывает скриншоты для визуального контроля. Подробности — `VERIFICATION.md`.

## Статус источников

Это действующий портал, но пока не полностью оцифрованный архив. Неимевшиеся оригиналы произведений, аудио, видео и анонсы не заменены вымышленными материалами. Ссылка на исходные документы дана в `SOURCES.md`. Для полнотекстовых публикаций нужны подтверждение прав, корректура и архивные файлы.
