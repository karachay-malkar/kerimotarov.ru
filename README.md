# Керим Отаров — живое слово

Авторский интерактивный макет цифрового литературного архива Керима Отарова.

## Запуск

Сайт не требует установки зависимостей или сборки. Нужен статический HTTP-сервер:

```bash
python3 -m http.server 8000 --directory .
```

Откройте http://localhost:8000 . При размещении на хостинге укажите корень репозитория как папку сайта. Относительные пути позволяют размещать сайт как в корне домена, так и в подпапке `/kerimotarov.ru/`.

## Состав

- `index.html` — разметка всех разделов и читателя.
- `style.css` — адаптивное оформление и анимации.
- `app.js` — библиотека, поиск, читатель, локальные заметки, словарь, биография и афиша.
- `assets/` — архивный портрет, локальные шрифты и их лицензии.
- `review/hero.jpg` — проверенный вид первого экрана.
- `DESIGN.md` — концепция.
- `SOURCES.md` — источники материалов.
- `VERIFICATION.md` — результаты проверок и ограничения.

## Статус

Это интерактивный макет. Полные тексты сборников и аудио/видеозаписи пока не загружены. Афиша демонстрационная; читательские заметки сохраняются только в браузере. Русский подстрочник короткого балкарского фрагмента подготовлен для демонстрации и требует редакционной сверки. Обложки созданы для макета.

## Публикация

GitHub Pages публикует корень ветки `main`. Файл `.nojekyll` отключает обработку Jekyll; `index.html` открывается напрямую. Workflow `.github/workflows/checks.yml` проверяет синтаксис JavaScript и не выполняет повторный деплой. Домен `kerimotarov.ru` подключается отдельно.
