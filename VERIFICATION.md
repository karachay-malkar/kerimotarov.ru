# Проверка сайта — 30 октября 2026

Новая архитектура проверяется GitHub Actions с помощью Playwright. Актуальные результаты и скриншоты доступны на вкладке Actions репозитория:
https://github.com/karachay-malkar/kerimotarov.ru/actions

## Автоматические сценарии

- Компьютер: Chromium 1440×900.
- Телефон: профиль Pixel 7 / мобильный Chromium.
- Проверки: короткая главная, загрузка архивного портрета, шесть прямых URL, полноэкранное меню и история браузера, поиск, SVG-кнопки, фильтры библиотеки, параллельный текст, заметки, избранное, режим reduced motion, отсутствие горизонтальной прокрутки.
- Отдельный тест делает визуальные снимки главной, меню, библиотеки и читателя; снимки публикуются в артефакте `visual-review` соответствующего workflow.

## Границы доказательства

Успешный e2e-прогон подтверждает работу проверенных пользовательских сценариев, а не эстетическую оценку и не идеальную производительность на каждом устройстве. Графические переходы зависят от поддержки View Transitions API; без неё навигация остаётся работоспособной. Сборку JavaScript подтверждает `node --check site.js`.

Полноценный архив потребует оригинальных материалов и подтверждённых прав. История Git сохраняет старую версию портала, но она больше не загружается.

## Новый регрессионный набор

Проверки дополнены обходом всех основных маршрутов и контролем: (1) у всех управляющих кнопок есть иконки Lucide из локального спрайта, (2) отсутствуют ручные `<path>` в разметке контролов, (3) меню меняет официальные иконки `menu`/`x`, (4) полоса прогресса связана с прокруткой, (5) режим уменьшения движения, (6) нет внешних CDN-запросов иконок. Текущее подтверждение прохождения смотрите в CI для HEAD ветки `main`; прежние результаты других коммитов не являются проверкой новых эффектов.
